# 医学影像二分类：胸部X光肺炎检测
基于PyTorch实现的胸部X光影像智能分类系统，采用ResNet18迁移学习方案，完成正常胸片与肺炎胸片的二分类判别，输出完整的模型评估指标与可视化结果。

## 项目背景
针对医学影像小样本场景，使用在ImageNet上预训练的卷积神经网络进行迁移学习，聚焦儿童胸部X光片的肺炎病灶检测任务。项目覆盖数据增强、模型训练、全量评估、推理部署全流程，可快速迁移至其他医学影像分类场景。

## 技术栈
- **深度学习框架**：PyTorch + TorchVision
- **骨干模型**：ResNet-18 迁移学习
- **数据处理**：灰度图标准化、随机翻转、随机旋转、中心裁剪
- **评估指标**：准确率、精确率、召回率、F1、混淆矩阵、ROC/AUC
- **可视化**：Matplotlib + Seaborn

## 数据集
采用Kaggle公开儿童胸部X光肺炎数据集，包含5863张标注胸片，已划分训练/验证/测试集。
- 类别：二分类（Normal 正常 / Pneumonia 肺炎）
- 标注来源：广州妇女儿童医疗中心，放射科医生校验
- 数据特点：灰度医学影像，存在类别不平衡（肺炎样本占比更高）

## 实验结果
### 核心指标（测试集）
| 指标 | 数值 |
|---|---|
| 测试集准确率 | **84.46%** |
| 肺炎精确率 | 80.21% |
| 肺炎召回率 | 99.74% |
| F1 分数 | 0.889 |
| AUC（曲线下面积） | **0.9723** |

> 结果说明：模型整体判别能力优秀（AUC接近0.98），对肺炎病灶的漏检率极低（召回率近100%）；正常胸片存在一定误判，主要由数据集类别不平衡导致，属于可优化点。

## 运行说明
### 1. 环境安装
```bash
pip install -r requirements.txt
```
### 2. 模型训练

```
python train.py
```

自动保存验证集准确率最高的模型权重至 `checkpoints/best_model.pth`。

### 3. 全量测试与评估

```
python test_evaluation.py
```

输出全部评估指标，自动生成混淆矩阵、ROC 曲线、样例预测三张可视化图片。

### 4. 单张图像推理

```
python infer.py
```

修改脚本内图片路径即可对单张胸片进行预测。

## 局限性与优化方向

1. **类别不平衡**：训练集肺炎样本远多于正常样本，导致正常胸片假阳性率偏高，可通过重采样、损失函数加权优化
2. **模型轻量化**：可替换为 MobileNet 等轻量骨干，适配边缘端部署
3. **任务扩展**：可升级为多疾病分类、病灶定位分割任务
4. **可解释性**：加入 Grad-CAM 等可视化方法，标注模型关注的病灶区域
